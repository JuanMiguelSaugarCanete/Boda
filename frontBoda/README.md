# frontBoda

Frontend público de la plataforma Boda.

## Scope

- Experiencia pública para invitados.
- Rutas de acceso, registro, panel, menú, itinerario, imágenes y canciones.
- Integración con `BO-USERS`, `BO-IMAGE` y `BO-SPOTIFY`.

## Tech Stack

- Astro
- React
- TypeScript

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run check
npm run build
```
